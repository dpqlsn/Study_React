조건부 렌더링
- React에서는 원하는 동작을 캡슐화하는 컴포넌트를 만들 수 있는데 이러면 애플리케이션의 상태에 따라서 컴포넌트 중 몇 개만을 렌더링 가능
- 렌더링 하고 싶지 않으면 NULL 사용

논리 연산자
- 조건이 참일 때 렌더링함 
  ex {isPacked ? name + ' ✅' : name} 일 때, isPacked가 참이면 (?) name + ' ✔'을 렌더링하고, 그렇지 않으면 (:) name을 렌더링함
- 단, 숫자를 쓰면 0이 렌더링 됨

리스트 렌더링
- React에서 데이터 배열을 필터링하고 변환하여 컴포넌트의 배열로 렌더링하기 위해 filter()와 map()을 사용
- 필터 : 원하는 데이터를 뽑아냄
- 맵 : 복사를 하기 위함

컴포넌트를 순수하게 유지하기
- 컴퓨터 과학에서(특히 함수형 프로그래밍의 세계에서는) 순수 함수는 다음과 같은 특징을 지니고 있는 함수
1. 자신의 일에 집중. 함수가 호출되기 전에 존재했던 어떤 객체나 변수는 변경하지 않음
2. 같은 입력, 같은 출력. 같은 입력이 주어졌다면 순수함수는 같은 결과를 반환
