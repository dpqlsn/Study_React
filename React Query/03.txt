Optimistic Updates
- 뮤테이션이 완료되기 전에 UI를 낙관적으로 업데이트하는 방법을 제시함
- onMutate 옵션을 사용하여 캐시를 직접 업데이트하거나 useMutation 결과에서 반환된 variables를 활용하여 UI를 업데이트할 수 있움

Via the UI
- 캐시와 상호작용 하지 않음
- 뮤테이션이 진행중일 때 다른 opacity를 가진 임시 항목을 렌더링함

Via the cache
- 데이터가 서버에서 새로 받아온 게 아니라 캐시에 저장되어 있던 것을 사용함

~ 낙관적인 결과를 표시해야 하는 곳이 하나만 있는 경우, variables를 사용하여 직접 UI를 업데이트하는 접근 방식이이 효율적

Query Cancellation
- 각 쿼리 함수에 AbortSignal 인스턴스를 제공
- 오래되었거나 비활성 상태가 되면 이 signal이 취소됨 즉, 모든 쿼리를 취소할 수 있음
- 보통 런타임 환경에 적용됨

Default behavior
- 기본적으로, Promise가 해결되기 전에 언마운트되거나 사용되지 않게 된 쿼리는 취소되지 않음
- Promise가 해결된 후에도 결과 데이터는 캐시에 남아 있음
- 하지만 AbortSignal을 사용하면 Promise가 취소됨

Scroll Restoration
- 웹 브라우저에서 이전에 방문한 페이지로 탐색할 때, 페이지가 이전에 있던 정확한 위치로 스크롤되어 있음

TanStack Query
- 모든쿼리에 대해 기본적으로 "스크롤 복원" 기능 제공, 왜냐면 쿼리가 렌더링될 때 동기적으로 검색할 수 있기 때문
- 쿼리가 충분히 오랫동안 캐시되어 있고(기본 시간은 5분) 가비지 컬렉션되지 않았다면, 스크롤 복원은 항상 자동으로 작동
