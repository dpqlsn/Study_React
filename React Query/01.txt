Overview
- 웹 어플리케이션을 위한 데터 패칭 라이브러리로 
  웹 어플리케이션에서 서버 state를 손쉽게 패칭하고 캐싱해주며, 동기적으로 업데이트를 할 수 있음

Motivation
- 서버 state가 가지는 특징
유저가 제어 및 접근 불가능한 위치(서버)에 데이터가 저장됨
페칭이나 업데이트를 할 경우 비동기 API를 사용
한 서버를 여러 사람이 함께 사용할 수 있고, 다른 사용자가 모르는 사이 데이터가 변경
잘못 설계할 경우 어플리케이션 내 데이터를 항상 최신 상태로 유지하지 못할 수 있음

CDN
모듈 번들러나 패키지 매니저를 사용하지 않는 경우, ESM.sh와 같은 ESM 호환 CDN을 통해 사용할 수 있음

Important Defaults
- 기본적으로 TanStack Query는 적극적이지만 합리적인 기본값으로 설정되어 있음
- 기본적으로 useQuery 또는 useInfiniteQuery를 통한 쿼리 인스턴스는 캐시된 데이터를 오래된 것으로 간주
- 더 이상 활성 인스턴스가 없는 쿼리 결과(useQuery, useInfiniteQuery 또는 쿼리 옵저버)는 "비활성"으로 표시되며 나중에 다시 사용될 경우를 대비하여 캐시에 남아 있음
