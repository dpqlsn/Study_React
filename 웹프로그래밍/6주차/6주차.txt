1. reduce()
   - 배열의 각 요소를 순회하면서 누적값(accumulator)을 계산하는 메서드
   - 각 요소를 누적값에 반영하여 하나의 결과값을 만드는 데 주로 사용

2. 매개변수
    - accumulator (acc): 누적값을 저장하는 변수. 초기값에서 시작하며, 각 반복마다 콜백의 리턴값으로 갱신됨
    - currentValue (cur): 현재 처리되는 배열 요소
    - currentIndex (index): 현재 요소의 인덱스 (선택적)
    - array: reduce를 호출한 배열 전체 (선택적)
    - 초기값 (initialValue): reduce의 두 번째 인자로 제공되며, accumulator의 초기값으로 사용

3. 구조 분해 할당
    - 구조 분해 할당 문법은 배열이나 객체의 속성을 해체하여 그 값을 개별 변수에 담을 수 있게 하는 JavaScript 표현식
    - 배열 구조 분해 할당 : 순서대로 값이 할당. 예를 들어, `[a, b] = [1, 2]`는 a=1, b=2가 됨
    - 객체 구조 분해 할당 : 객체의 key 이름에 따라 값이 할당. 기본값이나 중첩 구조도 사용 가능

4. Promise
    - 비동기 작업의 최종 완료 또는 실패를 나타내는 객체
    - Promise 생성자 :
        - 형식: `new Promise((resolve, reject) => { /* executor */ });`
        - executor 함수는 두 개의 매개변수 **resolve**와 **reject**를 받음
            - resolve(value) : 작업 성공 시 호출하며, 이 값은 Promise의 이행값이 됨
            - reject(reason) : 작업 실패 시 호출하며, 이 reason은 에러 객체나 이유가 됨

    - 메서드 :
    - `.then(onFulfilled, onRejected)`: Promise가 성공하면 onFulfilled, 실패하면 onRejected 콜백을 실행
    - `.catch(onRejected)`: 실패한 경우 처리할 콜백 함수
    - `.finally(onFinally)`: Promise의 성공/실패 여부와 상관없이 항상 호출

5. Async / Await
    - async 함수 : 함수 선언 앞에 async 키워드를 붙이면 해당 함수는 자동으로 Promise를 반환
    - await 키워드 : Promise의 이행을 기다리며, 함수 실행을 일시 중단하고 결과값을 반환받을 때까지 블록
    - 에러 처리 : try/catch를 사용하여 동기 코드처럼 에러를 처리

6. 클로저
    - 클로저는 함수가 자신의 렉시컬 환경을 기억하여, 외부 함수의 변수에 계속 접근할 수 있는 특성
    - 주로 데이터 은닉, 상태 유지, 함수 팩토리 등에서 활용
    - 외부 함수의 변수는 클로저를 통해 함수 외부로 '노출'되지 않고도 내부에서 사용할 수 있음
    - 함수가 실행된 후에도 관련 변수를 계속 유지
