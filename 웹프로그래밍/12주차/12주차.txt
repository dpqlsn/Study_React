1. 리터럴 타입
   : 변수나 함수가 특정 값만 가질 수 있도록 엄격하게 타입을 제한하는 방법 
     즉, 특정 값만 가질 수 있게 함
   ex ) let a : 1; // type을 지정해주는 대신 1을 사용

   : 여러 리터럴 값을 받을 수 있도록 OR 조건으로 나열하여 허용할 수 있음
    direction = 'left';  // ✅
    direction = 'down';  // ✅

    : 함수의 파라미터, 리턴 타입에도 리터럴 타입으로 지정 가능함
    : 의도하지 않은 값이 들어오는 것을 방지할 수 있음

    // 사용 예시
    advanceToThePlayoffs('KT');    // ✅
    advanceToThePlayoffs('LOTTE'); // ✅

2. 타입 별칭
   : 복잡한 타입이나 자주 쓰는 타입에 짧고 의미 있는 이름을 붙여서 더 쉽게 코드에 사용할 수 있도록 도와주는 문법 
     즉, 타입에 별명을 붙이는 것

     ex ) type UserId = string;

3. 함수 타입 표현식
  : 함수의 매개변수, 반환 형태를 타입으로 지정한 형태
  : 가독성, 확장성, 명확성 등의 이유가 있음 
  : 객체 내부에 함수 타입 표현식 활용하기 

  ex ) 

    function add(a: number, b: number): number {
    return a + b;
    }

    >>

    type Operation = (x: number, y: number) => number;

    const add: Operation = (a, b) => a + b;
    const subtract: Operation = (a, b) => a - b;
    const multiply: Operation = (a, b) => a * b;

4. 호출 시그니처
   : 함수 타입 표현식과 동일하게 함수의 타입을 별도로 정의하는 방식 

   ex ) 

    type Operation = {
    (x: number, y: number) => number;
    };

    const add: Operation = (a, b) => a + b;
    const subtract: Operation = (a, b) => a - b;
    const multiply: Operation = (a, b) => a * b;

5. 성능 최적화
- 코드 스플리팅
  : 전체 애플리케이션을 작은 청크로 나누어 필요할 때마다 로드할 수 있도록 하는 방식
    애플리케이션의 초기 로딩 시간을 크게 줄일 수 있으며, 사용자 경험을 향상시키는데 기여
  : 리액트와 같은 SPA는 프로젝트 빌드 시 하나의 JavaScript 파일로 빌드됨
  : 하나의 파일로 번들링 된 결과물을 배포할 시 처음 진입할 때 모든 페이지에 대한 정보를 불러오게 되고, 이는 초기 로딩속도를 늦추는 결과를 가져옴
  : javascript의 동적 import와 react에서 제공하는 lazy함수를 통해 컴포넌트들을 래핑해, 사용자에게 해당하는 컴포넌트들이 보여질 때만 렌더링할 수 있도록 설정할 수 있음 

6. useMemo, useCallback
  : 상태 변경 시, 컴포넌트 함수 자체가 다시 실행됨
  : 해당 과정의 비용적인 문제를 해결하기 위해 사용하는 훅으로 값(콜백)을 메모이제이션해 값을 캐싱함
  : 상태가 바뀌면 렌더링 됨, 단 쓸데없이 렌더링 되는 경우도 있음
